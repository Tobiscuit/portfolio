This hydration error is caused by browser extensions (like Grammarly) adding attributes to the body tag that don't match between server and client. The fix is to suppress hydration warnings for these external attributes:

---

Adding suppressHydrationWarning to body tag to prevent browser extension hydration errors

---

The hydration error was caused by browser extensions (like Grammarly) adding attributes to the body element that don't exist during server-side rendering. Adding `suppressHydrationWarning={true}` to the body tag tells React to ignore hydration mismatches for this specific element, which is safe since these are external modifications we can't control.
