Redesigning a Coffee Shop Mobile App

This project aimed to redesign a mobile application for a local coffee shop, focusing on improving user experience and increasing customer engagement. The process involved user research, wireframing, prototyping, and usability testing. The outcome was a sleek, intuitive app that boosted user satisfaction and sales.

My Role

Lead Designer

Contributions

  • Created wireframes and interactive prototypes to visualize the app's structure and functionality.

  • Collaborated with developers to ensure seamless implementation of the design.
